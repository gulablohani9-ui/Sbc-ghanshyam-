# Gulab Sarvatobhadra

GitHub-ready Android starter project for a Sarvatobhadra Chakra app.

Core UI:
- 9x9 / 81-cell Chakra
- 28 Nakshatra including Abhijit
- 20 consonant cells
- 12 Rashi cells
- 5 Tithi groups
- Centre Poorna
- Birth detail inputs
- Tap-cell interaction
- GitHub Actions debug APK workflow

Important: this first build is a working UI/prototype of the Chakra. It does NOT yet contain a verified astronomical ephemeris engine or full transit/vedha computation. Those should be added as a separate calculation module after the exact classical rule-set is fixed.
